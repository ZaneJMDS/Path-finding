# Path-finding



This is an algorithim to find an efficent path from the start to the end. 



Features:

* The program may find an efficient path with A\*.
* The program shall generate an adjancy matrix with weightings between each item.
* The program shall load level text files



Extensions:

1. The path finding algorithim could count how many nodes it has visited and display that to the user.
2. Allowing the user to place and remove items from within the application.

3\. Adding more obstacles, this could include locked doors and keys.

4\. Colors for items on the grid.
